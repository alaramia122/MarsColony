# MarsColony

Настольная многопользовательская стратегическая НРИ о создании устойчивой марсианской колонии с цифровым сопровождением.

## Цель MVP

Локальная настольная сессия до трёх часов. Домашний компьютер выполняет роль сервера, игроки подключаются браузерами по Wi-Fi. Голосовое управление реализуется через Яндекс Алису.

## Статус

## Проверка сценария локально

Требуется Python 3.12 или совместимая версия; внешние зависимости не нужны.

```bash
python -m json.tool data/scenarios/ares-01.json
python -m unittest discover -s tests -v
python tools/scenario_sim.py
```


## Структура репозитория

- `docs/` — GDD, техническое задание, экономическая модель, сценарии, план и ADR.
- `data/scenarios/` — машиночитаемые игровые сценарии.
- `tools/` — контрольные расчёты и проектные утилиты.
- `tests/` — автоматические проверки сценариев и доменных расчётов.
- `.github/workflows/` — CI и автоматизация.
- `AGENTS.md` и `docs/PROJECT_STATE.md` — переносимый контекст для продолжения работы.
