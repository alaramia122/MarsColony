# MarsColony

Настольная многопользовательская стратегическая НРИ о создании устойчивой марсианской колонии с цифровым сопровождением.

## Документация

- [Game Design Document](docs/GDD.md) — игровой мир, направления ответственности, цикл партии и ИИ-ведущий.
- [Техническое задание](docs/TECHNICAL_SPEC.md) — архитектура, API, клиенты, Алиса и критерии приёмки.
- [Экономическая модель](docs/ECONOMY_MODEL.md) — ресурсы, производство, население, инфраструктура и автономность.
- [План разработки](docs/DEVELOPMENT_PLAN.md) — этапы MVP, GitHub workflow, CI и проверки.

## Цель MVP

Локальная настольная сессия до трёх часов. Домашний компьютер выполняет роль сервера, игроки подключаются браузерами по Wi-Fi. Голосовое управление реализуется через Яндекс Алису.

## Статус

Начальная проектная документация находится в ветке `docs/initial-design`. Численные параметры экономики и баланс сценария уточняются на основе инженерных источников и плейтестов.
