# ADR-005: Физическое исполнение проектов через экономическое ядро

- **Статус:** принято для этапа 2
- **Дата:** 2026-11-15

## Контекст

Проектный workflow должен менять состояние колонии через проверяемые игровые механизмы. Простая смена статуса после согласования не отражает расход материалов, доступность труда, дефицит энергии, длительность работ и ввод результата в эксплуатацию.

## Решение

1. Карточка проекта задаёт материальные требования, агрегированную трудоёмкость в FTE, энергопотребление на период и ограниченный набор ожидаемых эффектов.
2. При запуске в одной транзакции проверяются и списываются материалы, проверяется свободный FTE и списывается ранее зарезервированный бюджет.
3. Активные проекты добавляют нагрузки в общую диспетчеризацию мощности с приоритетом ниже базовых систем колонии. Период засчитывается только при полном обеспечении проектной нагрузки.
4. Прогресс проекта увеличивается на один период только при полном обеспечении энергии. Недопоставка оставляет проект активным без прироста прогресса и создаёт событие аудита.
5. Завершение разрешено после достижения заданной длительности. При подтверждении результата сервер атомарно вводит инфраструктурные записи, периодический выпуск ресурсов и прирост мощности генерации.
6. Периодический выпуск ресурсов ограничивается вместимостью соответствующего хранилища. Дополнительная генерация применяется в следующих расчётных периодах.
7. Все эффекты задаются структурированными данными. Произвольная мутация состояния через JSON проекта запрещена.

## Последствия и границы

- Труд моделируется агрегированным FTE; профессии, квалификации и индивидуальные назначения будут отдельным расширением.
- Материалы списываются при запуске, без отдельной модели незавершённого производства и промежуточных складов.
- Энергия учитывается электрической нагрузкой; тепловые и детальные технологические модели строительства не входят в этап 2.
- Подтверждение завершения — отдельное действие уполномоченного участника, чтобы ввод объекта в эксплуатацию оставался контролируемым событием.
