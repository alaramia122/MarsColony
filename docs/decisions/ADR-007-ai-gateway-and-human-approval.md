# ADR-007: AI Gateway и граница полномочий ИИ

- Статус: принято для этапа 4
- Дата: 2026-11-15

## Контекст

MarsColony использует LLM для преобразования свободного текста в игровые предложения и для работы ИИ-ведущего. Игровое состояние принадлежит серверному движку. Нужна возможность менять модель и провайдера без изменений доменных модулей.

## Решение

1. Вызовы моделей проходят через отдельный AI Gateway.
2. Провайдер реализует интерфейс генерации типизированного результата.
3. На первом срезе используется адаптер OpenAI Chat Completions-compatible API; провайдер отключён по умолчанию.
4. Входной текст игрока и ответ модели считаются недоверенными данными.
5. Ответ проходит схему Pydantic и повторную доменную валидацию backend.
6. LLM не получает доступа к базе данных, игровым командам и секретам.
7. Предложения хранятся отдельно от проектов и имеют собственный жизненный цикл.
8. Создание предложения не изменяет состояние игры; пользователь явно преобразует его в обычный черновик проекта.
9. Обычные полномочия, согласования, резервирование ресурсов, исполнение и аудит применяются без обходных путей.
10. API-ключи передаются только через переменные окружения/секреты.

## Последствия

- Игровое ядро не зависит от конкретного поставщика моделей.
- Модель может быть заменена на YandexGPT, другой облачный или локальный backend при реализации соответствующего адаптера.
- Стоимость и лимиты внешнего API остаются явной конфигурацией.
- Предварительные оценки ИИ отделены от подтверждённых инженерных данных.
- Игрок сохраняет контроль над созданием и согласованием проектов.

## Ограничения

- Первый срез поддерживает только OpenAI-compatible chat completions.
- Провайдер должен возвращать корректный JSON в заданном контракте.
- Конкретная совместимость и авторизация российских провайдеров проверяются отдельно перед добавлением адаптера.
- Встроенный ИИ-ведущий, события и реестр сущностей входят в дальнейшую работу этапа 4.
