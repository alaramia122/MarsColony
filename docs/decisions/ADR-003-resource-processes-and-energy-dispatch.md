# ADR-003: Универсальные материальные процессы и диспетчеризация энергии

- **Статус:** принято для этапа 1
- **Дата:** 2026-11-15

## Контекст

Экономика MarsColony должна поддерживать расширение сценариев без переписывания расчётного ядра под каждый ресурс. Производство ограничивается сырьём, энергетикой, производительностью и вместимостью складов. При снижении генерации колония должна распределять доступную мощность по приоритетам и регистрировать отключённую нагрузку.

Сессия также должна сохранять параметры сценария, с которыми была создана: обновление JSON-файла не должно менять уже начатую партию.

## Решение

1. Материальные процессы описываются картами входов и выходов на цикл, удельным расходом энергии и запрошенным числом циклов.
2. Исполнитель рассчитывает доступный объём по наиболее жёсткому ограничению: входной запас, явно выделенная энергия или свободная ёмкость выходного склада.
3. Для агрегированных производств допускаются дробные циклы. Все количества выражаются в единицах ресурса, заданных сценарием; единицы измерения и точность должны быть формализованы до расширения каталога.
4. Электрические нагрузки имеют приоритет и минимальную устойчивую мощность. Распределение детерминировано и воспроизводимо.
5. Ares-1 использует общие механизмы для производства кислорода, пищи и воды, а также для диспетчеризации нагрузки во время обслуживания энергомодуля.
6. При создании сессии сохраняется JSON-снимок сценария. Существующие сессии рассчитываются по этому снимку.
7. API продвижения периода может принимать ожидаемый номер текущего периода; сервер отклоняет устаревшую команду после блокировки строки сессии.

## Последствия

- Новые рецептуры могут добавляться как данные без изменения общих правил выполнения процессов.
- Материальные дефициты, ограничения складов и отключённая нагрузка становятся явными элементами отчёта.
- Снимок сценария обеспечивает воспроизводимость исторических сессий.
- Модель аккумулятора пока проверяет резерв по ёмкости; состояние заряда, мощность преобразователей и КПД остаются отдельной задачей.
- Текущая реализация не заменяет детальную модель тепловых потоков, химических реакций, труда и оборудования; эти подсистемы подключаются по мере появления подтверждённых сценарных данных.
