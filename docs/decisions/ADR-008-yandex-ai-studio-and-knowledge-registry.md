# ADR-008: Yandex AI Studio и версионируемый реестр знаний

- Статус: принято для этапа 4
- Дата: 2026-11-15

## Контекст

MarsColony ориентирован на российскую аудиторию и инфраструктуру. AI Gateway должен поддерживать российский API наряду с OpenAI-compatible сервисами. ИИ-ведущий создаёт проектные инициативы, сводки, сценарные события и предложения новых знаний. Все результаты модели нуждаются в проверке и аудите.

## Решение

1. Добавить нативный адаптер Yandex AI Studio Foundation Models Text Generation API.
2. Использовать endpoint https://ai.api.cloud.yandex.net/foundationModels/v1/completion, Authorization: Api-Key, x-folder-id, modelUri и jsonObject.
3. Провайдер и секреты настраиваются только через переменные окружения; AI отключён по умолчанию.
4. Сводки, предложения проектов, сценарные события и сущности проходят отдельные типизированные контракты.
5. Уточнения проекта сохраняют историю версий и контекст диалога.
6. Сценарные события публикуются в журнал только после подтверждения командира; публикация не меняет экономические показатели.
7. Новые сущности получают версию и проходят проверку командира. Предыдущая активная версия сохраняется со статусом superseded.
8. Реестр знаний не изменяет расчётную модель без отдельного изменения доменного ядра и тестов.

## Последствия

- Можно использовать Yandex AI Studio в качестве основного российского провайдера.
- Контракты AI Gateway остаются независимыми от поставщика моделей.
- Игроки могут уточнять проектные инициативы без потери предыдущих версий.
- Сценарные события и новые знания становятся видимыми и аудируемыми объектами сессии.
- ИИ остаётся помощником ведущего и игроков, а не владельцем игрового состояния.

## Ограничения

- Реальный запрос к Yandex требует API-ключ, folder ID, роль сервисного аккаунта и расходуемую квоту/бюджет.
- Mock-тест проверяет формат HTTP-запроса и разбор ответа, но не заменяет проверку действующими учётными данными.
- Утверждённые сущности не становятся автоматически доступными производственным расчётам.
