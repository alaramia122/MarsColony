# ADR-002: Базовый численный сценарий Ares-1

- Статус: принят как базовая конфигурация для плейтеста
- Дата: 2026-11-15

## Контекст

Концептуальная экономическая модель не позволяла проверить игровые периоды, резервы, последствия отказов и продолжительность сессии. Для завершения проектной подготовки нужен воспроизводимый сценарий с явными единицами измерения, источниками и маркировкой допущений.

## Решение

1. Для первого сценария используется база Ares-1 с населением 24 человека.
2. Кампания длится 120 марсианских солов и состоит из четырёх периодов по 30 солов.
3. Человеческие нормы, заданные на земные сутки, пересчитываются через фактическую продолжительность марсианского сола.
4. Исходные ресурсы, мощности, бюджет, события и проекты хранятся в версионируемом JSON-файле `data/scenarios/ares-01.json`.
5. Контрольный расчёт реализуется отдельным инструментом на стандартной библиотеке Python; он не является игровым backend.
6. Инженерные ориентиры NASA отделяются от сценарных допущений. Масштабирование экспериментальных установок, стоимость проектов, цены, мощности базы и запасы имеют статус игровых допущений.
7. GitHub Actions проверяет корректность JSON и выполняет детерминированные сценарные тесты.

## Последствия

- У проекта появляется воспроизводимый базовый набор численных параметров.
- Изменение любого параметра может быть проверено тестами.
- Сценарий позволяет сравнивать решения и события на общей исходной конфигурации.
- Экономическая модель получает точку калибровки для плейтеста.
- Контрольный расчёт остаётся отдельным от будущего серверного движка и будет заменён или перенесён в доменную логику на этапе 1.

## Ограничения

- Базовый прогон не моделирует полную химию атмосферы, калорийность рациона, металлургическую цепочку и полный цикл ремонта.
- Скриптовое обслуживание энергетики проверяется отдельным расчётом критической нагрузки; оно не изменяет накопленную энергию в базовом прогоне.
- Проекты пока представлены параметрами и не исполняются симулятором.
- Сценарий не считается сбалансированным до настольного плейтеста.
