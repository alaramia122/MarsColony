## Назначение

MarsColony — многопользовательская настольная стратегическая НРИ о развитии устойчивой марсианской колонии с цифровым сопровождением. Цель MVP — локальная игровая сессия до трёх часов; игроки подключаются браузерами по домашней сети. Голосовой интерфейс планируется через Яндекс Алису.

## Зафиксированные решения

- Backend: Python и FastAPI; frontend: React, TypeScript и Vite.
- Хранилище игрового состояния: PostgreSQL.
- Обмен обновлениями: WebSocket.
- Развёртывание: Docker Compose; CI: GitHub Actions.
- Архитектура MVP: модульный монолит.
- Сервер — единственный источник истины для игрового состояния.
- ИИ формирует типизированные предложения; сервер проверяет их и применяет изменения после необходимых согласований.
- Алиса и браузерные клиенты используют единый API.
- ИИ-интеграция изолируется через AI Gateway.
- Экономическая модель имеет шесть связанных подсистем: материальную, энергетическую, биологическую, демографическую, финансовую и технологическую.
- Интерфейс предусматривает оперативный, аналитический и инженерный уровни детализации.

Подробные требования и обоснования находятся в GDD, техническом задании, экономической модели и ADR. Этот файл не заменяет их.

## Следующие шаги

1. Сформировать стартовый сценарий ранней марсианской базы с чёткими границами модели.
2. Разделить параметры на физические/инженерные данные, проектные решения и игровые допущения; указать источники и единицы измерения.
3. Задать исходные запасы, мощности, производство, потребление, персонал, бюджет, импорт и события.
4. Рассчитать несколько игровых периодов и проверить материальные, энергетические и финансовые балансы.
5. Проверить, что сценарий создаёт содержательные решения в рамках трёхчасовой партии.
6. После согласования сценария определить минимальный вертикальный срез backend и тесты.
7. Реализовать CI до начала развёртывания на домашнем компьютере.
