## Назначение

MarsColony — многопользовательская настольная стратегическая НРИ о развитии устойчивой марсианской колонии с цифровым сопровождением. MVP — локальная сессия до трёх часов, браузерные клиенты в домашней сети и голосовой интерфейс через Яндекс Алису.

## Принятые решения

- Backend: Python/FastAPI; frontend: React/TypeScript/Vite.
- PostgreSQL — постоянное хранилище; WebSocket — обновление клиентов.
- Docker Compose и GitHub Actions; на старте модульный монолит.
- Сервер — единственный источник игрового состояния; LLM формирует типизированные предложения, сервер проверяет их.
- Алиса и веб-клиенты используют единый API; AI Gateway не привязан к одному провайдеру.
- Экономика включает материальную, энергетическую, биологическую, демографическую, финансовую и технологическую подсистемы.
- UI имеет оперативный, аналитический и инженерный уровни детализации.
- Базовый численный сценарий — Ares-1: 24 человека, четыре периода по 30 солов.

Подробности и обоснования находятся в GDD, ТЗ, экономической модели и ADR.

## Контрольный результат Ares-1

При четырёх скриптовых событиях и без запуска дополнительных проектов контрольный расчёт заканчивается следующими запасами:
- кислород — 364,302 кг;
- сухие пищевые вещества — 322,818 кг;
- подготовленная вода — 2 867,114 кг;
- сырой лёд — 2 625 кг;
- бюджет — 500 кредитов.

Непокрытого спроса по кислороду, сухим пищевым веществам и воде в контрольном прогоне нет. Проверки охватывают перевод солов в земные сутки, балансы, резервирование критической нагрузки, ограничение добычи доступным сырьём, доступность бюджета и FTE.
